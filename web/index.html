    Claude in Chrome 등 브라우저 AI에게
    
        
    이 페이지는 AI용 JavaScript API window.godotAI를 제공합니다. 아래 안내문을 복사해 AI에게 붙여 넣으세요.
    
        
    이 탭은 GitHub 저장소와 동기화되는 Godot 4 웹 에디터야. Godot 화면(캔버스)을 클릭하지 말고, 페이지의 JavaScript API window.godotAI 를 사용해서 작업해 줘.
1. 먼저 godotAI.help() 와 await godotAI.status() 로 사용법과 상태를 확인해.
2. 파일은 godotAI.readFile / godotAI.writeFile 로 다루고, .tscn 같은 Godot 텍스트 형식을 지켜.
3. 결과는 await godotAI.setMainScreen('2D') 후 await godotAI.screenshot() 으로 확인하고, 오류는 await godotAI.logs({ level: 'error' }) 로 봐.
4. 변경은 자동으로 GitHub에 커밋되니 별도로 저장할 필요는 없어.
JavaScript를 실행할 수 없다면 오른쪽 "AI 패널"의 파일 탭(경로, 내용 입력란, 파일 저장 버튼)을 사용해.
